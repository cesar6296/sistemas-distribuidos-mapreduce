# Comandos para Ejecutar BROTHER

---

## macOS / Linux

### 1. Instalar librerias
```bash
pip3 install nltk flask
```

### 2. Ejecutar la matriz de similitudes (consola)
```bash
python3 similitudes.py
```

### 3. Levantar la pagina web
```bash
python3 app.py
```

### 4. Abrir en el navegador
Entra a:
http://127.0.0.1:5001
